## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Реализовать импорт YouTube-ссылки в библиотеку на основании согласованного дизайна FLQ-28.1. Результат — материал с названием видео, субтитрами на текущем изучаемом языке и сохранённой связью текста с таймкодами. Субтитры доступны как обычный учебный текст: карточки слов/фраз, словарь, статусы и SRS используют существующий поток Flinq. FLQ-28.1 предоставляет выбранный и проверенный способ импорта, правила дорожек/ошибок, соответствие текста и времени и контракт для reader. Само видео показывается через согласованный способ воспроизведения, а не становится новым файловым форматом импорта по умолчанию.

Учесть права доступа, приватность материала, обязательные поля общего контента, экспорт/удаление пользовательских данных и версию источника. Ошибки YouTube не должны создавать внешне готовый материал без валидного текста/таймингов. Редактирование текста выполняется только по согласованной политике сохранения синхронизации. Добавить тесты и документацию в этой подзадаче.
<!-- SECTION:DESCRIPTION:END -->

- [x] #2 Название видео импортируется, а выбранные субтитры соответствуют текущему изучаемому языку по согласованной политике дорожек.
- [x] #3 Импортированный текст пригоден для обычного изучения слов и фраз; связь текста с исходными таймкодами сохраняется после перезагрузки.
- [x] #4 Отсутствие субтитров, недоступное видео, неверная ссылка и временная ошибка сервиса различимы для пользователя и не создают ложного успешного результата.
- [x] #5 Доступ, редактирование, экспорт и удаление нового вида материала соответствуют существующим правам и согласованным правилам версий/таймингов.
- [x] #6 Тестами проверены успешный импорт, согласованные виды дорожек и ошибки; описаны настройка, ограничения источника и пользовательский сценарий.
