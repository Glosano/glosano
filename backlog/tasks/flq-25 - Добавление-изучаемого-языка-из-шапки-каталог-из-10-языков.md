## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Пользователь хочет добавлять новый изучаемый язык прямо из выпадающего меню выбора языка в шапке. Сейчас меню показывает только уже добавленные языки; изменение списка доступно отдельно в настройках и ограничено EN/RU/PT.

Сценарий: открыть меню в шапке → пункт «Добавить язык» → форма выбора → выбрать язык → сохранить → язык появляется в меню, становится текущим и открывается его библиотека. Отмена оставляет профиль без изменений. Добавление дополняет текущий список языков пользователя, сохраняя существующие уроки, словарь и прогресс. Уже добавленный язык нельзя добавить повторно.

Согласованный пользователем каталог — 10 языков всего, включая существующие: английский, русский, португальский, испанский, французский, немецкий, китайский (упрощённый), японский, арабский, хинди. Пользователь явно подтвердил весь список и расширение MVP до десяти языков 2026-09-11. Языки интерфейса остаются RU/EN.

Граница продукта: decision log §10.1 фиксирует EN/RU/PT, а §13 относит автоматическую поддержку множества языков к non-goals MVP. Расширение MVP scope явно подтверждено пользователем 2026-09-11; повторное согласование этого расширения не требуется. Перед реализацией зафиксировать решение новым ADR. Принятые решения не переопределять молча.

При проработке учитывать, что китайский и японский требуют правил выделения учебных единиц в текстах без пробелов, арабский — корректного направления текста; выбор языка не должен создавать неработоспособный профиль. Проверить совместимость каталога с импортом, reader, словарём, SRS и опциональным AI; при необходимости выделить связанные подзадачи до реализации. Отсутствие словарного пакета должно объясняться пользователю, базовый продукт сохраняет работоспособность без AI.

Флаги обязательны рядом с названиями языков в форме добавления, выпадающем меню шапки и отображении текущего языка. Предусмотреть единое соответствие: английский 🇬🇧, русский 🇷🇺, португальский 🇵🇹, испанский 🇪🇸, французский 🇫🇷, немецкий 🇩🇪, китайский (упрощённый) 🇨🇳, японский 🇯🇵, арабский 🇸🇦, хинди 🇮🇳. Существующие соответствия EN/RU/PT сохраняются. Флаг дополняет текстовое название; язык должен оставаться понятным без отображения флага и при использовании скринридера.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 В меню выбора изучаемого языка в шапке присутствует пункт «Добавить язык», открывающий форму выбора.
- [x] #2 Форма содержит каталог из 10 согласованных языков, обязательно отдельный пункт «Китайский (упрощённый)»; названия понятны в RU/EN интерфейсе.
- [x] #3 Уже добавленные языки недоступны для повторного добавления; если добавлены все языки, форма сообщает об этом.
- [x] #4 После сохранения язык добавляется в профиль, появляется в меню и становится текущим; открывается его библиотека, выбор сохраняется после перезагрузки.
- [x] #5 Отмена не изменяет профиль; ошибка сохранения явно показана и не отображается как успешное добавление; существующие языки и данные сохраняются.
- [x] #6 Новые языки согласованно принимаются профилем, настройками, выбором текущего языка и импортом; сценарий импорта и чтения проверен для упрощённого китайского.
- [x] #7 Форма доступна с клавиатуры и на мобильном экране; тексты локализованы RU/EN.
- [x] #8 Изменение языковых границ MVP явно согласовано и зафиксировано в новом ADR; тестами покрыты добавление, сохранение выбора, дубли, отмена и ошибки.
- [x] #9 В форме выбора, меню шапки и отображении текущего языка рядом с названием показан соответствующий флаг для каждого из десяти языков; название остаётся доступным для скринридера и при отсутствии изображения флага.
