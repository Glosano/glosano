## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Пользователь добавляет ссылку на YouTube, получает название видео и субтитры на изучаемом языке. Субтитры становятся интерактивным учебным текстом с обычными карточками слов и фраз. В reader сверху показано видео, под ним управление воспроизведением, ниже — текст субтитров. В режиме предложения воспроизводится только выбранный фрагмент с возможностью повторять его сколько угодно. В режиме страницы воспроизведение ограничено текущей страницей; пользователь дополнительно запросил переключатель «Листать автоматически», который разрешает непрерывное воспроизведение с переходом между страницами. Текущее звучащее предложение выделяется по таймкодам.

16.09.2026 пользователь явно подтвердил включение этого сценария в MVP, пересматривая прежнее исключение видео в decision log §13. Расширение ограничено YouTube и существующими субтитрами. Остальные медиа-возможности требуют отдельного решения.

До реализации согласовать дизайн и оформить новый ADR. Рекомендуется выключенный по умолчанию переключатель автоперелистывания и отдельные доступные кнопки воспроизведения/паузы/повтора под видео; это предложения дизайна, а не уже согласованные требования. Пользователь подтвердил: автоматический переход на следующую страницу отмечает оставшиеся new-слова покинутой страницы как known, как ручной Next. Tracked/known/ignored не меняются; сохраняется undo последнего bulk-known. Повтор фрагмента сам по себе не является переходом страницы. Политика выбора авторских/автоматических субтитров, поведение при их отсутствии, границы предложений и таймкодов, перемотка, открытие карточки слова и редактирование текста должны быть явно решены в дизайне.

Проверенные ограничения: официальный captions.download требует права редактировать видео; импорт обычного публичного ролика нельзя обещать на базе одного этого API. youtube-transcript-api — кандидат для исследования, его документация предупреждает о блокировках запросов. Способ получения субтитров и его пригодность для self-hosted проверяются до реализации.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Поддержка YouTube в MVP и согласованные правила импорта/проигрывания зафиксированы новым ADR и спецификацией с привязкой к ID задачи.
- [x] #2 Ссылка на поддерживаемое YouTube-видео создаёт материал с названием и субтитрами на изучаемом языке; текст доступен для обычного изучения слов и фраз.
- [x] #3 Reader показывает видео, управление под ним и интерактивный текст субтитров ниже.
- [x] #4 В режиме предложения воспроизведение останавливается в конце текущего фрагмента, и пользователь может повторять его без ограничения числа повторов.
- [x] #5 В режиме страницы выключенный переключатель автоперелистывания ограничивает воспроизведение текущей страницей; включённый разрешает непрерывное воспроизведение с переходом страниц.
- [x] #6 Текущее звучащее предложение выделяется по таймкодам без потери видимости статусов слов; текстовые материалы сохраняют существующее поведение.
- [x] #7 Автоматический переход на следующую страницу переводит оставшиеся new-слова покинутой страницы в known как ручной Next; остальные статусы сохраняются и доступна отмена последнего bulk-known.
