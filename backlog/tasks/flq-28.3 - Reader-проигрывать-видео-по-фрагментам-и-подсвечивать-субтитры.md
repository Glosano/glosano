## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Добавить в reader изучение импортированного YouTube-видео. FLQ-28.1 предоставляет согласованный дизайн управления/синхронизации и правил статусов, FLQ-28.2 — материал с названием, субтитрами, источником и таймкодами. Компоновка: видео, управление под ним, интерактивные субтитры ниже. Пользователь допускает отдельную заметную кнопку воспроизведения; конкретные контролы согласовываются в дизайне.

Sentence mode воспроизводит только изучаемый фрагмент и позволяет повторять его любое число раз. Page mode по умолчанию ограничивается текущей страницей; пользовательский toggle «Листать автоматически» разрешает непрерывное воспроизведение и переход страниц. Текущие предложения выделяются по времени видео, сохраняя голубую/жёлтую подсветку статусов. Пользователь подтвердил: при автоматическом переходе на следующую страницу оставшиеся new-слова покинутой страницы становятся known, как при ручном Next. Tracked/known/ignored не меняются; undo последнего bulk-known сохраняется. Повтор фрагмента сам по себе не вызывает перехода. Учёт чтения, перемотку через несколько страниц и реакцию на ошибки сохранения уточнить в дизайне; не считать их автоматически эквивалентом последовательного просмотра.

Сохранить обычные действия со словами/фразами, undo ручного bulk-known, подтверждение завершения и поведение текстовых уроков. Учесть перемотку, смену режима, границы страницы, паузы между субтитрами, ошибки плеера, повторное открытие материала, RU/EN и мобильный экран. Тесты и документация входят в подзадачу.
<!-- SECTION:DESCRIPTION:END -->
