## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Дать пользователю возможность исправлять и удалять ранее добавленные материалы прямо из библиотеки.

В правом верхнем углу каждой карточки материала размещается кнопка с тремя точками. По нажатию открывается меню с пунктами «Редактировать» и «Удалить». Работа с меню не должна открывать материал для чтения.

«Удалить» открывает окно с предупреждением и кнопками «Да» и «Отмена». Материал удаляется только после подтверждения «Да»; «Отмена» закрывает окно без изменений. После успешного удаления карточка исчезает из библиотеки.

«Редактировать» открывает отдельную страницу редактирования материала, не модальное окно. Форма заполнена текущими значениями. Доступны все поля материала в текущем пользовательском сценарии: «Название» и «Текст». Кнопки: «Сохранить» и «Отмена». Сохранение применяет изменения и возвращает в библиотеку; отмена возвращает в библиотеку без сохранения. Обновлённые название и текст должны отображаться в карточке и при чтении соответственно.

При реализации учесть существующие правила доступа и обработки материалов. До изменения текста определить поведение прогресса чтения и связанных данных урока; удаление или редактирование материала не должно неявно удалять личный словарь и карточки повторения. Эти детали нужно сверить с действующими решениями проекта.

Задача включает проверки основных сценариев и актуализацию затронутой документации.

- [x] #4 Нажатие «Отмена» в окне удаления закрывает его и сохраняет материал без изменений.

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Добавить тесты API на чтение исходного текста владельцем, обновление названия/текста, удаление, права доступа и сохранение словаря/SRS/статистики.
2. Добавить сервисные операции владельца и API GET edit, PATCH, DELETE. Изменение текста атомарно создаёт новую source version, перестраивает сегменты и вхождения, сбрасывает позицию/undo и ledger старого текста; накопленные счётчики сохраняются. Переименование не меняет прогресс. Блокировки согласовать с worker.
3. Добавить тесты UI, меню карточки и подтверждение удаления. На чужих общих материалах действия недоступны; сервер проверяет владельца.
4. Добавить отдельную страницу /learn/:lang/lessons/:id/edit с Названием, Текстом, Сохранить/Отмена, валидацией и обработкой ошибок. Обновить клиентские кэши после операций, локализации RU/EN.
5. Записать ADR о версиях при редактировании и обновить UI/API документацию. Проверить тесты frontend/backend, lint, типы, production build и интерфейс.

Ревью обнаружило риск применения старых ordinal-диапазонов из другой вкладки к новому тексту. Включить source_version в reader content и запись позиции/bulk-known; отклонять устаревшие версии с 409, удерживать блокировку урока между проверкой и операцией. Показывать понятное сообщение о необходимости обновить страницу. Это необходимо для безопасного редактирования текста по текущей задаче.
