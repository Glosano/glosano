# ADR-0017 — Числа не являются отдельными учебными словами

- Статус: Accepted; пользователь согласовал 2026-09-16.
- Задача: FLQ-29.
- Уточняет ADR-0001; заменяет ADR-0005 только в части обработки чисел.

## Контекст

Проверка `\w` признавала цифры словами: текст `It's 2020. You're the most
senior person on your team` содержал 10 учебных слов, а `2020` автоматически
переходило в `known`. Ручное игнорирование каждого числа не решает проблему.

## Решение

1. Отдельный учебный токен содержит хотя бы одну Unicode-букву (категории `L*`,
   `str.isalpha()` после NFC). Числа, знаки, подчёркивания и отдельные combining
   marks не являются учебными словами. Это правило едино для всех языков.
2. `2020`, десятичные числа, цифры арабского и деванагари письма, fullwidth-цифры
   и Unicode-числовые символы остаются видимыми в тексте без карточки и подсветки.
   Они не входят в word count, reading count, список слов урока и bulk-known.
   Границы токенов, исходный текст, offsets и ordinal не изменяются.
3. `B2B`, `3D`, `COVID-19`, а также числительные, записанные буквами (`twenty`,
   `двадцать`, `二十`), остаются словами. Лемматизация не вводится.
4. Числа внутри сохранённых фраз остаются частью их identity: `in 2020 alone`
   и `in 2021 alone` различаются. Нормализация существующих фраз не меняется.
   В API такие компоненты имеют `p/n/i`: отображение обычным текстом и данные
   для точного сопоставления фраз, без самостоятельного статуса слова.
5. Миграция исправляет `is_word_like` существующих occurrences и word count.
   Для сохранившихся occurrences вычитает ошибочно учтённые чтения. История
   удалённых/заменённых материалов, которую нельзя достоверно восстановить,
   сохраняется. Нетронутые числовые записи `added_by=bulk, status=known`
   переводятся в `ignored`, сохраняя ID. Явные пользовательские записи,
   переводы, заметки, теги и SRS-история не изменяются.
6. Ручной словарь и импорт пользовательских записей остаются доступны для
   намеренно сохранённых чисел. Автоматически новые числовые записи не создаются.

## Последствия

В приведённом примере 9 слов. Новые и существующие уроки используют одинаковое
правило после обновления БД. Перелистывание и undo для настоящих слов сохраняются.
Изменение не добавляет отдельную пользовательскую операцию bulk-ignored.

Миграция является исправлением данных без изменений схемы; downgrade не
возвращает ошибочные счётчики и не отменяет последующие действия пользователя.
Для восстановления прежних значений нужна резервная копия.
