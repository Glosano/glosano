# ADR-0022 — Грамматические теги карточки слова

- Статус: Accepted
- Дата: 2026-09-23
- Задача: FLQ-31
- Дополняет ADR-0001 и ADR-0003; не меняет единицу обучения и LLM-провайдера.

## Контекст

При чтении нужны короткие подсказки: часть речи, начальная форма и время глагола.
Пользователь согласовал получение этих сведений из AI или ручной ввод и сохранение
тегов для добавленных слов. В приложении уже есть персональные `item_tags`.

## Решение

Используем существующие персональные теги. Добавляем источник `user / ai`;
исторические теги считаются ручными. Текст тега остаётся ключом дедупликации в рамках
пользователя и записи. AI добавляет только отсутствующие теги; явный ручной ввод
имеет приоритет. Источник сохраняется в экспорте и отображается в карточке и списках
словаря. Начальная форма — справочный тег, не сущность Lemma и не способ объединить
статусы, статистику или SRS разных словоформ.

Грамматические сведения запрашиваются через существующий OpenAI-compatible adapter
в отдельной операции `/api/ai/word-tags`. AI получает выбранное слово, язык и текущее
предложение. Ответ валидируется: часть речи — ограниченный код, начальная форма
и время — строки до 64 символов или `null`. Неверный ответ не показывается как теги.
Время используется только для глагола / вспомогательного глагола; для неопределённой
или невременной формы поле отсутствует. Часть речи отображается на языке интерфейса,
начальная форма и название времени — на изучаемом языке.

Для нового слова сведения автоматически предлагаются при открытии карточки.
Просмотр не создаёт запись в словаре. При явном добавлении слова сохраняются и теги,
включая случай, когда AI завершает уже начатый запрос после добавления. Сохранение
самого слова и перевода не блокируется ожиданием или ошибкой AI.

Для существующей записи генерация запускается только отдельной кнопкой.
Обычное повторное открытие показывает сохранённые теги; удалённые теги не должны
восстанавливаться из кэша. Запросы из разных предложений/слов и пользователей
разделены; поздний результат сохраняется только для исходной записи.

Под словом в обеих версиях карточки показываются компактные серые теги с переносом.
Сами теги не имеют действий. `Тег+` открывает ручной ввод; отдельный режим изменения
показывает кнопки удаления. Для фраз сохраняется ручное управление тегами, без
автоматического грамматического разбора.

`GLOSANO_LLM_ENABLED=false` запрещает вызовы провайдера. Сохранённые данные и ручное
управление доступны независимо от AI. Ошибки генерации и сохранения разделены,
ошибка сохранения не очищает ручной ввод. AI-данные всегда помечаются как AI.

## Последствия

Нужна добавочная миграция `0023_item_tag_source`; существующие теги не изменяются.
Три AI-тега сохраняются одной транзакцией. Модель обучения и словарный импорт
не требуют изменений или морфологических зависимостей. Новый автоматический запрос
для нового слова увеличивает число AI-вызовов; клиент повторно использует результат
в пределах сессии и контекста. Качество лингвистического разбора зависит от настроенной
модели, а не гарантируется проверкой формата ответа.
