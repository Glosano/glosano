# ADR-0014 — Подтверждённое завершение материала в ридере

- Статус: Accepted; частично заменён [ADR-0023](ADR-0023-reader-end-of-material-page.md) — способ подтверждения (страница завершения вместо диалога «Да/Нет»).
- Дата: 2026-09-13
- Задача: FLQ-27; постановка подтверждена пользователем, реализация поручена явно.
- Дополняет ADR-0005, ADR-0010 и ADR-0013; их решения сохраняются.

## Контекст

На последней странице/предложении отсутствует переход вперёд, запускающий
bulk-known. Позиция у конца текста сама по себе не подтверждает завершение.

## Решение

На последнем фрагменте галочка «Завершить материал» открывает диалог «Да/Нет».
Подтверждение атомарно обрабатывает только новые слова текущего фрагмента,
учитывает чтение по ADR-0010 и сохраняет завершение для пользователя.
Tracked/ignored/known сохраняются. Пропущенные фрагменты не обрабатываются.
Автоматические записи known сохраняют added_by=bulk, без провенанса изучения.

В reader_positions добавляются nullable completed_at и completion_action_id
(UUID идентификатора BulkAction, без внешнего ключа). Уникальная позиция
(user_id, lesson_id) сериализует подтверждения; повтор завершения возвращает
тот же результат. Схема не выводит завершение из старых позиций 100%.
Обычные записи позиции и перечитывание сохраняют completed_at.
Проверка source_version под блокировкой материала защищает от старых вкладок.
Последний сегмент и конечный диапазон проверяются сервером; в sentence mode
диапазон точно соответствует словам последнего предложения. У фрагмента без
слов обе границы null. Завершить материал без слов допустимо, счётчики слов
остаются нулевыми.

Undo операции завершения снимает completed_at и completion_action_id и отменяет
только её bulk-known по существующим правилам. Факт чтения остаётся. Позиция
чтения не откатывается: процент позиции может оставаться 100%, но явной отметки
«Материал завершён» больше нет. Ошибка undo позволяет повторить попытку.
Изменение текста удаляет ReaderPosition и BulkAction по ADR-0013, сбрасывая
завершение; изменение только названия сохраняет его.

Ридер после подтверждения остаётся открыт, показывает завершение, кнопку undo
и переход в библиотеку. При повторном открытии статус загружается с сервера;
завершённый материал можно перечитывать. Ридер и карточка библиотеки показывают
100% для завершённого материала, включая материалы без слов. Завершение
доступно без AI. RU/EN, клавиатура и свайп используют один сценарий подтверждения.

## Последствия

Нужна миграция 0018. Статус завершения явно отделён от позиции и знания слов.
Новый POST /api/reader/complete сохраняет слова и завершение одной транзакцией.
Экран итоговой статистики остаётся необязательной идеей из FLQ-27.
