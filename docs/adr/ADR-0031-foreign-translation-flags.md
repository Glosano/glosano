# ADR-0031 — Флаг только у переводов не на родном языке

- Статус: Accepted
- Дата: 2026-10-18
- Задача: FLQ-47 (исправление после приёмки)
- Уточняет: [ADR-0030](ADR-0030-native-language-translation-target.md), раздел
  «Сохранённые переводы» — фраза «каждый перевод показывается с флагом своего
  языка»

## Контекст

ADR-0030 ставил флаг языка у каждого сохранённого перевода. Пользователь,
у которого родной язык не менялся, видел флаг родного языка у всех слов —
шум без информации. Флаг нужен только чтобы отделить переводы, оставшиеся
от прежнего родного языка.

## Решение

Флаг языка показывается у сохранённого перевода только тогда, когда язык
перевода отличается от текущего родного языка пользователя. Переводы на
родном языке идут без флага. Правило одинаково для карточки слова (список
вариантов и пустое поле для нового перевода), словаря `/vocabulary`
(таблица и мобильный список), списков слов в ридере, карточек и итогов
сессий SRS.

Для скринридеров флаг декоративен, вместо него читается название языка.
Остальные правила ADR-0030 (выбор одного перевода, фолбэк на другой язык,
редактирование) не меняются.

## Последствия

Пока родной язык не меняли, флагов в интерфейсе нет. После смены родного
языка флагами отмечены только «старые» переводы. При смене родного языка
обратно флаги у них снова исчезают — это производное отображение, данные
не меняются.
