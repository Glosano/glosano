# ADR-0021 — Обычный текст ответа AI-чата

- Статус: Accepted — пользователь подтвердил 2026-09-19.
- Дата: 2026-09-19.
- Задача: FLQ-30.
- Дополняет ADR-0018 и ADR-0020; заменяет внутренний NDJSON-контракт ответа из интеграционного отчёта.

## Контекст

После перехода от упражнений к свободному обсуждению worker продолжал требовать
построчные JSON-записи от модели. Успешный HTTP-ответ провайдера мог отклоняться
как `invalid_output`, если модель отвечала обычным текстом или Markdown.
Повторный запрос с просьбой исправить формат не гарантировал успеха.
Пользователь явно поручил убрать это требование.

## Решение

Содержимое `delta.content` стандартного Chat Completions SSE-потока — обычный
текст ответа. Оно последовательно сохраняется и показывается существующим
безопасным Markdown renderer. Непотоковый ответ использует `message.content`
с теми же правилами. Нет внутреннего NDJSON, JSON Schema ответа, лимита
4000 символов на один абзац и отдельной format-repair попытки.

Сохраняются общий предел 64000 символов ответа, запрет пустого результата,
проверка завершения транспортного потока и token truncation, deadline,
Stop, AI-off и проверка владельца перед публикацией. Ошибки транспорта после
первых фрагментов не повторяют уже показанный текст автоматически.

История assistant передаётся модели обычным текстом, чтобы не обучать её
возвращать прежнюю JSON-обёртку. Пользовательское сообщение может сохранять
JSON-конверт для исторических вложений; system prompt явно отделяет этот
формат входных данных от обычного текстового ответа.

JSON и примеры кода в ответе — только текст. Они не создают упражнения,
попытки, оценки или записи SRS. Команды практики остаются отключёнными.
Уже сохранённая история и миграции не переписываются.

## Последствия

Свободный чат не требует от модели дополнительного структурного протокола.
Обычный ответ и Markdown больше не приводят к `invalid_output` из-за формата.
Проверки используют plain-text ответы, потоковые фрагменты и JSON-примеры как
данные; качество объяснений конкретной модели остаётся отдельным вопросом.
