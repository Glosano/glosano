# ADR-0011 — Язык перевода совпадает с языком интерфейса

- Статус: Accepted
- Дата: 2026-09-11
- Задача: FLQ-9
- Связан с: ADR-0003, ADR-0008, FLQ-9 settings design

## Контекст

В onboarding существовали независимые настройки языка интерфейса и перевода.
Пользователь согласовал единое направление: учебный материал EN/RU/PT
переводится на выбранный язык интерфейса EN/RU.

## Решение

`user_profiles.ui_language_code` определяет язык новых переводов, инструкций
и обратной связи AI. Поле `preferred_translation_language_code` сохраняется
для совместимости и синхронизируется при регистрации, onboarding и изменении
настроек. Миграция 0017 синхронизирует существующие строки. Legacy-поле
`translation_language` в запросах onboarding допускается, но не меняет целевой язык.

Очередь SRS и AI-упражнения выбирают сохранённые переводы на языке UI.
При отсутствии такого перевода приложение не подставляет перевод другого языка.
Сохранённые переводы, заметки, учебные тексты и ответы пользователя не переписываются.
Изменение языка не меняет статусы или историю обучения. Удаление языка из списка
изучаемых не удаляет связанные пользовательские данные.

AI feedback и пояснения используют язык UI; предложения и правильные ответы
сохраняют педагогическое направление упражнения. Язык включён в промпт и
его hash; клиентские ключи запросов различают пользователя и целевой язык.
Контекстные подсказки не кэшируются в backend; аудит содержит только метаданные.
Кэш переводов предложений теперь изолирован по `(user_id, segment_id, target_language_code)`.
Старые строки без владельца сохраняются, но не выдаются пользователям.
Экспорт включает только собственные записи кэша, включая переводы чужих shared-уроков.
Миграция 0017 добавляет nullable user_id и каскад удаления; downgrade запрещён,
пока существуют персональные записи кэша, чтобы не потерять их или не сделать общими.
При отключённом AI сохраняется существующее поведение без внешних вызовов.

## Последствия

Отдельного выбора языка перевода больше нет. Пользователь может переключить
интерфейс для новых переводов, сохранив ранее записанные варианты. Старое значение
независимой настройки после миграции восстановить невозможно; downgrade
сохраняет совместимые EN/RU значения и не меняет личный словарь.

## Настройки аккаунта и данные

Дневная цель в минутах: 1–1440, личная настройка без учёта времени.
Дневной лимит SRS: 1–10000, default 500. Смена пароля требует текущий пароль
и новый длиной 10–128; другие сессии удаляются, текущая сохраняется.

JSON export schema_version=1 содержит явный перечень полей всех личных таблиц
и дочерних данных собственных уроков. Исключены credentials, session tokens,
общие dictionary tables и системный statistics_tracking. Импортированные файлы
хранятся как текст урока и payload задания в PostgreSQL; отдельных пользовательских
файлов на диске нет. Удаление использует PostgreSQL cascades по ADR-0008,
включая статистику ADR-0010; shared-уроки других пользователей и общий словарь
сохраняются.
