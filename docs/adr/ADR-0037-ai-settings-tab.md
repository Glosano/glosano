# ADR-0037 — Настройки AI внутри общего раздела настроек

- Статус: Accepted
- Дата: 2026-10-21
- Задача: FLQ-11
- Частично заменяет [ADR-0036](ADR-0036-admin-ai-settings.md): расположение UI и маршрут страницы. Остальные решения сохраняются.

## Контекст

Отдельные пункты «Настройки AI» и «Настройки» в меню аккаунта разделяют связанные
действия. Пользователь попросил оставить один вход в настройки и перенести AI во
вкладку внутри этого раздела.

## Решение

- В меню аккаунта остаётся один пункт «Настройки».
- В общей навигации настроек рядом с профилем, предпочтениями и данными появляется
  вкладка «Настройки AI» по адресу `/settings/ai`, видимая только администратору.
- Форма использует общий layout настроек без второй шапки или вложенной страницы.
- `/admin` и `/admin/ai` перенаправляют на `/settings/ai` для сохранения старых ссылок.
- Проверка роли в форме и серверные права `/api/admin/ai` не меняются: learner
  не может получить или изменить конфигурацию, в том числе по прямой ссылке.

## Последствия

Вход в AI-настройки: меню аккаунта → «Настройки» → «Настройки AI».
Хранение, диагностика, шифрование, применение конфигурации и аварийное отключение
продолжают следовать ADR-0036. Это изменение навигации, без расширения возможностей
администратора.
