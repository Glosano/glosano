# ADR-0015 — Экран итогов чтения

Статус: Accepted. Задача: FLQ-27. Дата: 2026-09-13.
Дополняет ADR-0010 и ADR-0014: пользователь явно поручил добавить экран итогов.

## Решение

После подтверждённого завершения показывается экран итогов вместо текста.
Можно перейти в библиотеку, продолжить чтение, открыть итоги повторно или
отменить завершение. Ошибка получения статистики не отменяет успешное завершение.

Снимок сохраняется в `BulkAction.payload_json.completion_summary` в той же
транзакции, что и завершение. Схема БД не меняется. POST `/api/reader/complete`
возвращает снимок; GET `/api/lessons/{id}/completion-summary` возвращает сохранённый
результат текущего завершения для авторизованного пользователя с доступом к уроку.
Незавершённый урок возвращает 404. Старые завершения без снимка возвращают
`summary: null`: интерфейс объясняет отсутствие данных и не подставляет нули.

## Определения метрик

- `total_words`: word-like вхождения текущего текста; повторяющиеся слова учитываются.
- `unique_words`: уникальные нормализованные словоформы по ADR-0001.
- `known_words/new_words/tracked_words/ignored_words`: разбиение уникальных слов
  всего материала по статусу непосредственно **перед финальным bulk-known**.
  Это не состояние на начало чтения и не число выученных за урок слов.
  Ignored не включается в known. Все четыре показателя в сумме дают unique_words.
- `marked_known_words`: число записей, созданных финальной операцией bulk-known.
- `added_words/added_phrases`: сохранённые записи текущего пользователя с
  `created_from_lesson_id` этого урока. Провенанс присваивается только при явном
  взятии на изучение (FLQ-21). Считаются и ранее автоматически созданные known,
  впоследствии взятые на изучение здесь; неактивные/выученные записи не исключаются.
  Удалённые до завершения записи не восстанавливаются. Провенанс относится к
  материалу в целом, включая предыдущие версии текста.
- `reading_days`: число различных дат UTC в DailyReadOccurrence текущего пользователя
  и урока, после учёта финального фрагмента. Повтор в один день не добавляет день.
  Пустой текст без записанных вхождений даёт 0. Дни без событий не восстанавливаются.
  Редактирование текста очищает ledger по ADR-0013, поэтому дни относятся к текущей версии.

Словарные показатели выбираются одним SQL statement. Снимок не меняется при
последующем перечитывании, изменении словаря или повторе запроса завершения.
Undo делает итоги недоступными как текущее завершение; новое завершение создаёт
новый снимок. Правила удаления пользователя, экспорта payload и сброса при
изменении текста остаются прежними. Общая статистика, streak и время чтения
не добавляются.

Клиент передаёт ожидаемый `action_id` при запросе итогов. Если другая вкладка
создала новое завершение, сервер отвечает `409 completion_changed`; экран
предлагает обновить материал и блокирует отмену устаревшей операции. Потерянный
ответ undo (`already_undone`) сверяется с актуальным состоянием урока, чтобы
не скрыть более новое завершение другой вкладки.
