# ADR-0025 — Транзакция на запрос и коммит до ответа

- Статус: Accepted
- Дата: 2026-09-27
- Задача: FLQ-19; вариант выбран пользователем.
- Связано с [ADR-0006](ADR-0006-tech-stack.md) (FastAPI + SQLAlchemy async).

## Контекст

Эндпоинты получали сессию через `Depends(get_session)`. `get_session` — зависимость
с `yield`: после обработчика она коммитит транзакцию, при исключении откатывает.

В FastAPI 0.136 код после `yield` по умолчанию (`scope="request"`) выполняется уже
после отправки ответа клиенту. Клиент получал «200, вы вошли», а сессия в БД ещё не
была записана. Следующий запрос (`GET /me` сразу после логина или регистрации)
иногда получал 401. На живом стеке это воспроизводилось в 2 случаях из 30.
Ошибка коммита после отправки ответа тоже терялась: клиент видел 200 за
несохранённую запись.

FastAPI 0.121 добавил `Depends(..., scope="function")`: код после `yield`
выполняется до формирования ответа. Проставить scope глобально или для роутера
FastAPI не позволяет.

Отдельно обзор кода показал три стиля управления транзакциями без общего
правила: неявный коммит зависимостью (`auth`, `me`, `reader`, `review`),
коммит в обработчике (`api/chats.py`, `api/lessons.py` перед постановкой
задачи в очередь) и коммит в сервисе (`modules/vocabulary`, `reader_state`,
`review`, `dictionary`).

## Решение

**Одна транзакция на запрос, коммит до ответа.** Эндпоинт получает сессию
только через алиас из `glosano.core.db`:

```python
SessionDep = Annotated[AsyncSession, Depends(get_session, scope="function")]
```

Успешный обработчик коммитит транзакцию при выходе из зависимости до отправки
ответа. Исключение, в том числе `HTTPException`, откатывает её. Прямой
`Depends(get_session)` в эндпоинтах не используется. Тест
`tests/api/test_session_commit_timing.py` обходит все маршруты и падает, если
какой-то маршрут получает `get_session` не с `scope="function"`.

**Явный `commit()` — только в двух случаях:**

1. Перед внешним побочным эффектом, которому нужны закоммиченные строки:
   постановка задачи в очередь воркеру, который открывает свою сессию
   (`api/lessons.py`, `api/chats.py`).
2. Восстановление после гонки на уникальном ограничении: `commit()` →
   `IntegrityError` → `rollback()` → перечитать победителя
   (`modules/vocabulary/service.py`, `modules/reader_state/translations.py`).

Сервисы и репозитории принимают `AsyncSession`, делают `flush()`, когда нужны
идентификаторы, и в остальных случаях коммит не вызывают. Ошибки из
обработчиков сообщаются исключением, а не `return JSONResponse(status_code=4xx)`,
иначе транзакция закоммитится.

Воркеры, CLI и middleware открывают собственную сессию через `session_scope()`.

Минимальная версия FastAPI — 0.121 (`backend/pyproject.toml`).

## Отклонённые варианты

- **`Depends(get_session, scope="function")` в каждом эндпоинте.** Правило
  размазано по 54 местам, и новый эндпоинт легко его забудет.
- **Явные транзакции в сервисах (`async with session.begin():`).** Границы
  транзакций видны в коде, но придётся переписать все пишущие сценарии, а
  забытый `begin()` молча теряет запись. Имеет смысл, когда сервисы начнут
  собирать несколько операций в одну транзакцию; тогда — отдельный ADR.
- **Unit of Work.** Избыточен для приложения такого размера.
- **Сессия в middleware или contextvar.** С `BaseHTTPMiddleware` передача
  контекста между задачами ненадёжна, и момент коммита снова зависит от
  потоковой передачи ответа.
- **Готовые интеграции (например, `advanced-alchemy` с `commit_mode`).** Новая
  зависимость ради одного правила; момент их коммита относительно отправки
  ответа не подтверждён.

## Последствия

- Ответ «успешно» означает, что запись уже в БД. Следующий запрос клиента её
  видит, а ошибка коммита возвращается клиенту как 500.
- Существующие явные коммиты в сервисах `vocabulary`, `reader_state`, `review`
  и `dictionary` вне двух разрешённых случаев остаются как есть. Их можно
  привести к правилу при следующей правке этих модулей.
- Потоковые ответы (`StreamingResponse`, SSE) не могут использовать `SessionDep`
  после возврата из обработчика: сессия уже закрыта. Сейчас таких эндпоинтов нет.
