# ADR-0032 — Девять языков интерфейса, английский как исходный

- Статус: Accepted
- Дата: 2026-10-18
- Задача: FLQ-48; дизайн — `docs/superpowers/specs/FLQ-48-ui-languages-design.md`
- Уточняет: [ADR-0012](ADR-0012-ten-learning-languages.md) в части «UI … остаются
  EN/RU»; [ADR-0030](ADR-0030-native-language-translation-target.md) в части
  «`ui_language_code` (EN/RU)»; decision log §2 строка 21 и §10.1 «Язык UI»
- Связан с: ADR-0006, ADR-0018, ADR-0022

## Контекст

Интерфейс доступен только на EN и RU, хотя изучать можно десять языков
(ADR-0012). Учащиеся с родным PT, ES, FR, DE, ZH-Hans, JA или HI видят
интерфейс на чужом языке. Ключами каталога переводов служат русские строки,
поэтому каждый новый язык пришлось бы переводить с русского, а формы
множественного числа заведены отдельными русскими ключами.

## Решение

Язык интерфейса (`ui_language_code`) выбирается из девяти кодов: `en, ru, pt,
es, fr, de, zh-Hans, ja, hi` — каталог изучаемых языков ADR-0012 без `ar`.

Арабский не поддерживается как язык интерфейса: он требует зеркального
RTL-интерфейса, а проверить его некому. Арабский остаётся изучаемым языком и
языком перевода.

Исходный язык каталогов интерфейса — английский: ключ в коде — английский
текст, русский и остальные языки — переводы с него. Каталоги поддерживают
формы множественного числа по CLDR (`Intl.PluralRules`) и явный контекст для
одинаковых английских строк с разным смыслом.

До входа язык интерфейса — явный выбор на этом устройстве, иначе первый
поддерживаемый язык браузера, иначе английский. После входа действует язык из
профиля.

Переводы на новые языки выполняются LLM-агентом без вычитки носителями.
Расширение браузера (ADR-0024) остаётся на прежних языках.

Всё, что ADR-0030 относит к `ui_language_code` (пояснения AI-чата, обратная
связь упражнений, подписи грамматических тегов), следует любому из девяти
языков.

## Последствия

- Учащийся может пользоваться интерфейсом на родном языке, если он входит в
  девять.
- Качество машинного перевода интерфейса не проверено носителями; ошибки
  исправляются по обращениям пользователей.
- Каждая новая строка интерфейса требует перевода на восемь языков в том же
  изменении; тест полноты каталогов не даёт пропустить язык.
- Арабский интерфейс потребует отдельного ADR (RTL-вёрстка, тестирование).
