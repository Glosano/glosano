# FLQ-8 — Статистика в выпадающей сводке

Статус: реализовано, 2026-09-10.

## Объём и интерфейс

Согласованный с пользователем объём и подписи: [docs/ui/stats.md](../../ui/stats.md).
Только выпадающая сводка в AppTopBar, без отдельного маршрута статистики.
Новые слова — записи, впервые добавленные в изучение сегодня, сутки UTC.
Монеты, аудио, streak, цели и последние уроки в этот инкремент не входят.

## Данные

Решение о хранении принято в [ADR-0010](../../adr/ADR-0010-statistics-reading-accounting.md).

`GET /api/stats/overview?lang=en|ru|pt` требует существующей пользовательской сессии.
Язык валидируется, все запросы ограничены user_id и language_code.

Текущие known/tracked/ignored считаются из token_items и phrase_items. Источник
добавлений — самое раннее created_at среди review_items одной identity (item_kind,
item_id); повторная активация не меняет дату первого добавления. Выученные на
повторении — уникальные identity с успешной graduation за сутки. Доступные повторения
берутся из существующего review service. UTC-границы используются как [start,end).

Чтение учитывается при bulk-known, в той же транзакции. Вставка word-like вхождений
в daily_read_occurrences с ON CONFLICT DO NOTHING RETURNING даёт число реально
новых вхождений; им атомарно увеличиваются дневной общий и языковой счётчики.
Диапазоны сортируются по ordinal, чтобы конкурирующие запросы брали блокировки
в одном порядке. Undo статусов не отменяет факт чтения. Повторное чтение в другие
UTC-сутки учитывается заново. Миграция 0016 сохраняет реальную дату начала учёта.

## Клиент

React Query использует ['stats', lang, UTC-date], обновляет данные при открытии,
смене суток, возвращении на вкладку и через существующий invalidateVocabularyViews
после словарных/reader/review изменений. В открытой панели периодический refetch —
60 секунд. Ошибка не подменяется нулями; данные другого языка не используются.

Radix Popover обеспечивает закрытие, позиционирование и управление фокусом.
Локальные SVG экспортированы из Figma без изменения содержимого. Каталог
public/assets/statistics не пересекается с dev-proxy /stats.
Шапка переносит навигацию на вторую строку при ширине менее 768 px.

## Проверки

- Postgres/Redis: API, изоляция пользователей/языков, реальные переходы reader/review,
  UTC-границы, конкурентные перекрывающиеся диапазоны, upgrade/downgrade миграции.
- Frontend: открытие/закрытие, фокус, ошибки/retry, смена языка, пустое состояние,
  смена суток и инвалидация после mutations.
- Browser QA: ширины 320, 375, 640, 768, 1280 px; нет горизонтального переполнения,
  SVG загрузились, Escape возвращает фокус. Визуальная проверка использует
  тестовые ответы API; реальные запросы проверяются интеграционными тестами.

## Ограничения

История чтения до миграции не восстанавливается из текущих позиций. SRS-показатели
опираются на сохранённую историю SRS. Автоматическая очистка occurrence ledger
не добавлена. Миграция применяется при обновлении приложения; рабочая база
пользователя в ходе разработки не изменялась.
