# FLQ-25 — Добавление изучаемого языка

Согласовано: пользователь подтвердил каталог, расширение MVP, флаги и поручил реализацию.

Каталог и продуктовые ограничения: ADR-0012. Форма в шапке показывает десять языков с флагами и локализованными названиями; уже изучаемые disabled. Выбор одного языка + «Добавить» сохраняет его на сервере, обновляет профиль и открывает библиотеку. В состоянии ожидания повторная отправка заблокирована. Отмена не сохраняет; ошибка оставляет форму доступной для повторной попытки. Если все языки добавлены — понятное пустое состояние.

Контракт: `POST /me/learning-languages` с JSON `{language_code: string}` возвращает полный `MeResponse`, добавляет язык и делает текущим в одной транзакции. Повтор идемпотентен. Проверяются auth, CSRF, каталог и наличие профиля. Блокировка строки пользователя сериализует добавления. Настройки/онбординг/маршруты используют тот же фиксированный каталог.

Backend: централизованный `LearningLanguageCode` Literal и набор допустимых кодов; переиспользуются vocabulary, reader, review, stats, dictionary, AI. `tokenize(text, *, base_offset=0, language_code=None)` и `normalize_phrase(surface, *, language_code=None)` сохраняют прежние вызовы; импорт и vocabulary явно передают язык. Китайский/японский сегментируются локально; combining marks сохраняются, Unicode sentence punctuation поддерживается. API отображения reader сохраняет исходные пробелы.

Frontend: общий `LEARNING_LANGUAGES`, тип `LearningLanguageCode`, функции поиска метаданных и направления; форма добавления, меню, онбординг, настройки, статистика используют каталог. UI EN/RU, текущий язык перевода EN/RU. RTL только на учебном тексте.

Проверки: добавление/повтор/сохранение текущего языка/невалидный код/auth/CSRF, выбор при ошибке/отмене, все языки добавлены, локализация/флаги/клавиатура, сохранение старых языков и настроек. Сквозной китайский импорт → worker → reader → vocabulary → review/stats без AI. GET /api/dictionary/lookup добавляет `availability: available | not_installed`; отсутствие активного пакета объясняется в карточке слова. Регрессия импорта текста/файла и прежних EN/RU/PT.
