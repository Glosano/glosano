# UI spec — страница `Reader` (`/lessons/$lessonId`)

- Статус: Draft v1
- Дата: 2026-05-01
- Макет-референс: `docs/ui/reader_no_sidebar.png` (sentence mode), `docs/ui/reader_w_sidebar.png` (page mode со сайдбаром карточки)
- Связано с: ADR-0005 (статусы, confidence, подсветка), `docs/architecture/2026-04-11-mvp-architecture-overview.md` §7.3, §10.2, `docs/specs/2026-04-11-mvp-product-alignment-design.md` §9, ADR-0001 (token/phrase)
- Связан со спекой карточки: `docs/ui/word_card.md`

## 1. Назначение

Reader — основной экран продукта. Отвечает за:

- отображение текста урока с подсветкой статусов (`new` / `tracked`);
- bulk-known переход при нажатии «next» (страница или предложение — см. §9);
- клик по слову/фразе → открытие карточки;
- запуск review-сессии из контекста текущего урока;
- сохранение reader-position между сессиями.

## 2. Маршрут и доступ

- Путь: `/learn/:lang/lessons/:lessonId`, где `:lang ∈ {en, ru, pt}` (decision log §10.1).
- Доступ: `learner` (любой урок со `visibility=shared` или собственный `private`).
- **Без query-параметров.** View mode и текущий segment — client-state и серверная сессия (`reader_positions`), не URL.
- Resume: при заходе бэкенд отдаёт `reader_positions.current_segment_id` пользователя.

## 3. Два view mode

В MVP поддерживаем два режима, переключаемых из bottom toolbar:

| Mode | Что показывает | Когда удобен |
|---|---|---|
| `page` | Длинный текст: ~200–400 слов, скролл, опциональный side panel с активной карточкой | Чтение длинных текстов, обзор |
| `sentence` | Один сегмент по центру (sentence или paragraph), крупно, без сайдбара. Под сегментом — мини-список tracked items этого сегмента | Глубокий разбор фрагмента, прослушивание |

Текущий mode — **client-state** (Zustand reader store), default берётся из `user_settings.reader_view_mode` при открытии. Toggle меняет state и persist'ится обратно в settings (debounced).

> **Решение по page size:** в `page` mode страница = ~250 слов (±50 для выравнивания по границе предложения). Точное число — open question в decision log §11, рекомендация: 250 слов как начальный default, конфигурируется через user settings.

> **Решение по segment unit в `sentence` mode:** базовая единица — `sentence`. Переключение на `paragraph` — open question, в MVP только sentence.

## 5. Layout — `page` mode

Аналогичный top bar и bottom toolbar, но:

- Текст урока скроллится в основной колонке (max-width ~720px).
- Опциональный right sidebar (toggle через [→| ] в top bar):
  - **Скрыт по default:** карточка слова открывается как **bottom sheet** (mobile) или **floating panel** справа (desktop, если viewport позволяет).
  - **Показан:** карточка живёт прямо в sidebar, без overlay над текстом. Удобно при долгом изучении одного урока.
- Внизу страницы кнопка **«Next page»** — триггерит bulk-known (см. §9); в `sentence` mode то же делает «Next sentence».
- Слева кнопка **«Prev page»** — без bulk-эффекта, просто навигация.

## 6. Подсветка токенов в тексте

По ADR-0005:

| Статус | Стиль |
|---|---|
| `new` | **Бледно-голубой fill** (`bg-sky-100` / `--reader-new-bg`). Cursor pointer на hover. |
| `tracked` | **Жёлтый fill** (`bg-yellow-200` / `--reader-tracked-bg`). В MVP равномерный — confidence-gradient отложен (open question ADR-0005). |
| `known` | Без выделения (как обычный текст). |
| `ignored` | Без выделения. Опциональный dotted-underline — open question; в MVP не показываем. |

> **Deviation от макета LingQ.** В `reader_no_sidebar.png` `new` слова показаны dotted-underline. Мы используем бледно-голубой fill согласно ADR-0005 — это решение зафиксировано, не меняем.

**Phrase highlighting:** если token входит в сохранённую `phrase_item`, статус фразы доминирует над статусом отдельного токена. Граница фразы рендерится одним непрерывным span'ом без gap'ов между токенами.

## 8. Vocab list под сегментом (sentence mode)

Под основным предложением показываем горизонтальные мини-карточки tracked items из этого сегмента (см. макет, нижний блок).

Состав карточки:
- Confidence indicator: круг с числом `0..5` (цвет — yellow scale; для `0` пилюля без fill).
- Surface text слова/фразы.
- 🔊 (post-MVP).
- Перевод (primary `personal_translations.translation_text`).

Действия:
- Click на карточку → открытие основной word card (см. `word_card.md`).
- В MVP **inline-редактирование confidence из этого мини-блока не поддерживается** (только через основную карточку), чтобы не дублировать контролы.

`new` слова в этот блок не попадают (нет персистентной записи). `known`/`ignored` тоже не попадают — это блок «что я учу здесь».

## 9. Bulk-known при переходе вперёд (`page` и `sentence` mode)

ADR-0005 §«Переходы»:

- Нажатие **«Next page»** переводит **все `new` occurrences текущей страницы** в `known`.
- В `sentence` mode нажатие **«Next sentence»** делает то же самое для диапазона ординалов текущего предложения — логика едина в обоих режимах.
- `tracked`/`known`/`ignored` не затрагиваются.
- Переход назад (prev page / prev sentence) — без bulk-эффекта, просто навигация.
- Предложение без слов (только пунктуация) пропускается без bulk-запроса.
- Backend создаёт `bulk_actions` запись с `payload_json` со списком созданных `token_items`.

**UX обратимости:**
- После клика «Next page» / «Next sentence» в нижней части экрана появляется **toast** с текстом «N слов помечены как known» и кнопкой **«Отменить»** (live ~6 секунд).
- Toast также повторяется в области footer как persistent **«Отменить bulk-known»** на текущей странице (до перехода ещё дальше).
- Отмена — POST `/reader/bulk-actions/{id}/undo`.

## 11. Phrase selection

- **Desktop:** click + drag по соседним токенам, либо `Shift+click` на второй токен от уже выделенного. Появляется флоат-кнопка «Save as phrase» → создаёт `phrase_item` со статусом `tracked` confidence `1`.
- **Сенсорные экраны (FLQ-32.2):** удержание слова 400 мс (сдвиг меньше 10 px) начинает
  выделение — слово подсвечивается, телефон коротко вибрирует, если умеет. Дальше палец
  ведётся по словам: правила те же, что у мыши (только предложение начального слова,
  не больше 8 слов, пунктуация слот не занимает). Под шапкой ридера плашка показывает
  текст фразы и «Не больше 8 слов» при упоре в лимит. Отпускание на двух словах и больше
  открывает карточку фразы, на начальном слове — карточку слова; синтетический click после
  отпускания гасится. Сдвиг до срабатывания — обычная прокрутка или свайп; после
  срабатывания прокрутка блокирована, а распознаватель свайпа сброшен, чтобы протягивание
  вбок не перелистнуло страницу. Если страница уже прокручивается (прокрутка во время
  ожидания или неотменяемый touchmove после срабатывания), выделение отменяется без
  карточки. `touchcancel` сбрасывает выделение. Системное выделение
  и меню долгого нажатия на тексте ридера отключены (`user-select`, `-webkit-touch-callout`,
  `contextmenu`), поэтому копировать текст ридера на сенсорных экранах нельзя. В карточке
  слова ридера на сенсорных экранах есть подсказка «Удерживайте слово и ведите пальцем,
  чтобы выделить фразу».

После создания phrase: подсветка немедленно обновляется (через TanStack Query invalidate).

## 12. Состояния

### 12.1 Loading lesson
Skeleton: серый блок с пульсацией на месте текста. Top bar и bottom toolbar активны.

### 12.2 Lesson `processing`
Урок ещё обрабатывается worker'ом (segmentation, tokenization). Показываем full-screen state: «Урок готовится» + spinner + estimated time. Polling `GET /lessons/$id` каждые 2 секунды.

### 12.3 Lesson `failed`
Full-screen error: причина + кнопки «Retry» (re-trigger import job) и «Удалить урок».

### 12.4 Network error при action
Inline toast «Не удалось сохранить» + retry. Optimistic update откатывается.

## 13. Mobile layout (<md)

- Top bar схлопывается: `[☰] progress [⋯]`, [Aa] переезжает в `[⋯]` меню.
- Боковые стрелки «‹ ›» скрыты на ширине < 640 px (FLQ-32.1): перелистывание — свайпом (§13.1),
  завершение — страница завершения (§17). Отступ ридера 16 px вместо 24 px, у блока
  предложения нет правого отступа; левое поле под плюс абзаца сохраняется. На 375 px
  текст занимает 311 px вместо 279 px.
- Sidebar toggle недоступен — карточка всегда как bottom sheet.
- Bottom toolbar: только два главных действия (toggle mode + review), остальное — в `[⋯]`.

### 13.1 Свайп (FLQ-32.1, все сенсорные экраны)

Свайп влево делает то же, что «›» (bulk-known с тостом отмены, на последнем
фрагменте — страница завершения §17), вправо — то же, что «‹». Поскольку свайп
вперёд меняет статусы слов, засчитывается только намеренный жест:

- один палец — второе касание (pinch-zoom) отменяет жест;
- страница не увеличена (`visualViewport.scale ≤ 1.01`);
- старт не ближе 24 px к левому или правому краю экрана — там системный жест
  «назад» iOS/Android;
- старт не на кнопке, ссылке, поле ввода или iframe; слова и фразы текста
  (`span[role=button]`) управлением не считаются;
- ось фиксируется по первым 10 px движения: если движение ближе к вертикали, чем
  `|dx| ≥ 2·|dy|`, это прокрутка, и жест уже не засчитывается;
- при отпускании `|dx| ≥ max(60 px, 18 % ширины экрана)` и `|dx| ≥ 2·|dy|`;
- при отпускании нет выделенного текста.

Визуальной «тяги» страницы за пальцем нет.

## 14. Связь с backend

- `GET /lessons/$id` — метаданные урока + текущая позиция.
- `GET /lessons/$id/page?seg=$segId&size=N` — content страницы / сегмента с pre-resolved статусами токенов и подсвеченными phrase occurrences для текущего пользователя.
- `GET /lessons/$id/sentence?seg=$segId` — один сегмент + связанные tracked items (для vocab list).
- `POST /reader/positions` — обновление `reader_positions` (debounced).
- `POST /reader/bulk-actions` — bulk-known.
- `POST /reader/bulk-actions/$id/undo` — отмена.
- Карточка слова — отдельные endpoints (см. `word_card.md` §10).

Backend module owner: `Reader State` (см. architecture overview §7.3).

## 15. Open questions

- **Page size:** 250 слов default — нужно валидировать на реальных текстах. Конфигурируемое в settings.
- **Segment granularity в sentence mode:** sentence vs paragraph toggle — отложен.
- **Confidence gradient в подсветке `tracked`:** в MVP равномерный жёлтый.
- **Phrase auto-highlight в других уроках:** open question decision log §11.
- **Audio / TTS / AI simplify:** post-MVP, заглушки скрыты.
- **Hotkey conflicts:** проверка на mac/windows (Ctrl vs Cmd).
- **Reader font choice:** один sans-serif вариант в MVP или давать выбор пользователю.

## 16. Не входит в MVP

- TTS (генерация аудио, sentence audio play, audio sync).
- AI-симплификация текста.
- Bilingual line-by-line view (§7.4 спеки — Phase 2).
- Hidden translation mode.
- Offline cache.
- Phrase auto-matching across lessons.
- Bulk-ignored на странице.
- Image translation для встраиваемых картинок.
## 17. Завершение материала (FLQ-27, ADR-0014, ADR-0023)

Переход вперёд с последней страницы или последнего предложения/фрагмента —
стрелка «›», ArrowRight или свайп — открывает виртуальную страницу завершения
вместо текста. Сам переход ничего не записывает: позиция, прогресс и статусы
остаются как на последнем фрагменте. Стрелка «›» на странице завершения неактивна.
Переход назад (стрелка «‹», ArrowLeft, свайп вправо или «Вернуться к тексту»)
возвращает последний фрагмент без побочных эффектов; смена режима и смена урока
тоже закрывают страницу завершения. Видео-автоперелистывание на неё не переходит.

Для незавершённого материала страница показывает «Вы всё прочитали», строку
«Новые слова последней страницы будут отмечены как известные» (если там есть
new), кнопки «Завершить материал» и «Вернуться к тексту». Для завершённого —
«Материал завершён», «В библиотеку», «Повторить лексику урока» и «Вернуться к
тексту». Фокус при входе — на заголовке, а не на кнопке: повторный или зажатый
Enter со стрелки «›» не должен завершать материал. Плашка «Материал завершён»
под ридером на странице завершения скрыта.

«Завершить материал» выполняет `POST /api/reader/complete` с версией материала,
режимом чтения, ID последнего предложения и границами текущего фрагмента.
У фрагмента без слов границы null. Сервер одной транзакцией отмечает оставшиеся
new текущего фрагмента как known, учитывает прочитанные слова и сохраняет
персональное завершение. Повтор запроса возвращает ту же операцию. Остальные
статусы и пропущенные фрагменты не меняются.

Ошибка оставляет страницу завершения с сообщением и возможностью повторить.
После успеха открывается экран итогов; «Продолжить чтение» возвращает последний
фрагмент, где ридер показывает «Материал завершён», «Отменить завершение»
и ссылку в библиотеку. Фокус переходит на сообщение об успехе. Кнопка отмены
доступна и при нуле новых слов; Ctrl/Cmd+Z отменяет последнее bulk-действие.
Отмена завершения снимает его отметку и отменяет созданные им known по правилам
ADR-0005, сохраняя учёт чтения и позицию. Ошибку сохранения/отмены можно повторить;
повтор уже выполненной отмены согласует интерфейс с сервером.

Завершение сохраняется после перезагрузки и при перечитывании. Ридер и карточка
библиотеки показывают отметку и 100% даже у материала без слов. Изменение текста
сбрасывает завершение; переименование его сохраняет. Устаревшая вкладка получает
предложение обновить страницу, не применяя диапазоны к новой версии текста.
Завершение и итоговый снимок включены в JSON-экспорт пользователя.
Экран итогов описан ниже.

## Экран итогов чтения (FLQ-27, ADR-0015)

После «Завершить материал» вместо текста открываются итоги: объём во вхождениях и уникальных
словоформах, known/new/tracked/ignored перед финальной обработкой, число слов,
отмеченных известными при завершении, сохранённые слова/фразы, взятые на изучение
из материала, дни фактического чтения текущей версии по UTC. Подписи различают
вхождения, словоформы и момент снимка; исторические показатели не реконструируются.

«Продолжить чтение» возвращает текст; кнопка «Итоги чтения» в статусе завершения
снова открывает экран. Есть переход в библиотеку и отмена завершения. Итоги
доступны после перезагрузки, снимок не изменяется вместе со словарём. Ошибка загрузки
позволяет повторить запрос и продолжить чтение; legacy завершение без снимка
показывает пояснение. RU/EN, мобильная сетка, фокус после завершения — на сообщении
об успехе; горячие клавиши ридера на экране итогов отключены.

## Видео и синхронные субтитры (FLQ-28, ADR-0016)

YouTube-плеер располагается над текстом; Play/Pause и повтор — под видео.
Iframe загружается после явного Play, сохраняется при навигации и смене режима.
Подпись показывает фактический язык и авторскую/автоматическую дорожку.
При недоступном видео изучение локального текста остаётся доступным.

Режим «Фрагмент» ограничивает воспроизведение одним фрагментом, режим страницы —
всеми фрагментами страницы. Play после конца начинает интервал сначала, повтор
всегда начинает сначала. Штатный Play YouTube подчиняется тем же границам.
Открытие карточки слова, выделение, ручная навигация, смена режима и скрытие вкладки
останавливают воспроизведение. Закрытие карточки не возобновляет его автоматически.

«Листать автоматически» изначально выключен и доступен в режиме страницы.
Включённый toggle продолжает видео и перелистывает на начале следующей страницы;
в паузах субтитров нет подсветки. Новые слова покинутой страницы становятся known
с прежней семантикой tracked/ignored и Undo. Перемотка не отмечает пропущенные
страницы. Пока сохранение не завершено, следующий переход приостанавливает видео.
Ошибка оставляет текущую страницу и предлагает повторить тот же запрос; после
повтора Play нажимается явно. Undo приостанавливает видео и выключает auto toggle.

Текущий фрагмент выделяется одним прямоугольным контуром вокруг всех его строк
и aria-current; цвета статусов слов сохраняются. В режиме страницы видеофрагменты
имеют блочную раскладку, поэтому смена активного фрагмента не меняет переносы текста.
В начале фрагмента показана зелёная кнопка-ярлычок с белыми цифрами времени и
значком Play. Нажатие переносит видео к этому времени и сразу запускает плеер;
при первой загрузке учитывается последний выбранный таймкод. Последний
фрагмент останавливается без автоматического завершения материала: страница
завершения и экран итогов продолжают работать по ADR-0023/0014/0015.
